# 🔑 مدير التراخيص — License Admin (Nexora)

تطبيق مستقل لمالك النظام فقط: تفعيل وترقية اشتراكات عملاء «مدير الحسابات»
مباشرة في نفس قاعدة Firebase RTDB دون أي تعديل يدوي.

## المزايا
- 📊 بطاقات إحصائية حية فور الفتح: إجمالي المساحات / مدفوعون / تجربة / منتهية.
- ✅ تفعيل بنقرة: ألصق بصمة الجهاز (من رسالة واتساب) أو معرف المساحة، اختر
  الخطة (فردي/مؤسسة) والمدة (شهر/3 أشهر/سنة/دائم) وسعة الأجهزة.
- 🕒 كل الحسابات بساعة خادم فيربيس حصراً (server_ts + المدة) — لا ساعة الهاتف.
- 📜 سجل المشتركين: آخر التفعيلات وحالتها الحية وزر «تمديد بنقرة» يبني فوق
  المدة المتبقية.

## 🆕 إصلاحات 1.1.0 (2026-09-22) — لماذا كان التطبيق «لا يعمل»
1. **الهوية الإلزامية**: قواعد RTDB تشترط `auth != null` على كل عقدة تلمسها
   اللوحة، فكانت كل قراءة/كتابة تُرفض بـ 401. الآن يُنشئ التطبيق هوية
   مجهولة تلقائياً (Firebase Auth) ويُجدّدها، ويرفق `?auth=` بكل طلب.
2. **الرابط الرسمي مضمّن**: كان فارغاً فتحتاج إعداداً يدوياً — الآن يعمل
   فور التثبيت، مع إمكانية التجاوز من ⚙️.
3. **سجل التفعيلات**: كان يُكتب في `/admin` المحجوبة بالقواعد فيُسقط
   التفعيل بعد نجاح الاشتراك — صار داخل `workspaces/<ws>/admin_log`.
4. **حسم المساحة المكررة**: جهاز يظهر في أكثر من مساحة عمل كان يُحلّ
   لأول مطابقة (مساحة ميتة) فيبدو الترخيص كأنه لا يُفعّل. الآن يُرجَّح
   الأحدث نشاطاً (`last_sync_at`) ثم الأكمل خطة، وإن تعذّر الحسم يُبلغك
   بالمرشحين لتختار.

## خطوات التشغيل
1. ثبّت `license-admin.apk` (يبنيه CI تلقائياً) على هاتفك فقط — لا يوزَّع للعملاء.
2. الرابط مضبوط مسبقاً — يعمل فور الفتح. إن أردت قاعدة أخرى افتح ⚙️
   وألصق الرابط (`https://xxxx-default-rtdb.firebaseio.com`)؛ مفتاح
   المصادقة اختياري إذ تُنشئ اللوحة هويتها تلقائياً.
3. عندما يرسل العميل رسالة واتساب فيها «بصمة التفعيل» ألصقها في الحقل الأول،
   اختر الخطة والمدة، ثم [تفعيل وترقية الحساب].
4. يلمس العميل التفعيل فوراً عند ضغطه «تأكيد عملية الشراء» في تطبيقه —
   دون مسح بيانات أو إعادة تثبيت.
