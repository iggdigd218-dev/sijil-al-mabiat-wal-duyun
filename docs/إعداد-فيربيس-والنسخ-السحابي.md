# دليل إعداد Firebase والنسخ السحابي — مدير الحسابات (Nexora)

التطبيق يدعم ثلاث قنوات سحابية مستقلة، ولا يحتاج أياً من ملفات `google-services.json` — الاتصال كله عبر REST مباشرة:

| القناة | ماذا تفعل | ماذا تحتاج |
|---|---|---|
| **المزامنة السحابية التزايدية** (Firebase Realtime Database) | ترفع كل عملية جديدة (حساب/عملية/سند/…) للسحابة وتسحبها بقية الأجهزة تلقائياً كل ~45 ثانية — مزامنة بين أجهزة بعيدة خارج شبكة Wi-Fi الواحدة | رابط قاعدة Realtime Database |
| **النسخة الكاملة برمز** (Firebase أيضاً) | ترفع/تسحب نسخة احتياطية كاملة واحدة مرتبطة برمز قصير (مثل `K7KQ2`) تتشاركه أجهزتك | نفس الرابط + رمز سحابي |
| **Google Drive** | نسخة احتياطية كاملة في مجلد التطبيق الخاص داخل حساب Google (appDataFolder) | تسجيل دخول Google على أندرويد فقط |

---

## أولاً: إنشاء مشروع Firebase (مرة واحدة، ~5 دقائق)

1. افتح **https://console.firebase.google.com** وسجّل الدخول بحساب Google.
2. اضغط **Add project / إضافة مشروع** → اختر اسماً (مثل `nexora-ledger`) → أكمل (يمكن تعطيل Analytics).
3. من القائمة الجانبية: **Build → Realtime Database** → **Create Database**.
4. اختر الموقع الأقرب (مثل `europe-west1`) → ابدأ في **locked mode**.
5. انسخ رابط القاعدة الظاهر أعلى الصفحة، سيكون بأحد الشكلين:
   - `https://nexora-ledger-default-rtdb.firebaseio.com`
   - `https://nexora-ledger-default-rtdb.europe-west1.firebasedatabase.app`

## ثانياً: قواعد الأمان (Rules)

في تبويب **Rules** داخل Realtime Database، الصق أحد الخيارين:

### خيار أ — الأبسط (حماية بسرّية الرابط والرمز فقط)
يناسب البدء السريع؛ أي من يعرف الرابط يستطيع القراءة/الكتابة، فحافظ على سرّيته:

```json
{
  "rules": {
    "workspaces": { ".read": true, ".write": true },
    "codes":      { ".read": true, ".write": true }
  }
}
```

### خيار ب — مقيّد بتسجيل دخول Google (أكثر أماناً)
التطبيق يرسل توكن Google تلقائياً إن كنت مسجلاً دخولك (شاشة إعدادات المزامنة):

```json
{
  "rules": {
    "workspaces": { ".read": "auth != null", ".write": "auth != null" },
    "codes":      { ".read": "auth != null", ".write": "auth != null" }
  }
}
```

> ملاحظة للخيار ب: يجب تفعيل **Authentication → Sign-in method → Google** في نفس مشروع Firebase، وأن تسجّل الدخول داخل التطبيق من: الإعدادات → المزامنة → «تسجيل الدخول بحساب Google». التوكن تنتهي صلاحيته بعد ساعة تقريباً؛ التطبيق يعالج ذلك بإعادة المحاولة، لكن مع القواعد المقيّدة يلزم فتح التطبيق دورياً لتجديد الجلسة.

## ثالثاً: ربط التطبيق

### المزامنة التزايدية (تلقائية بين الأجهزة)
على **كل جهاز**:
1. الإعدادات → قسم **المزامنة** → «المزامنة السحابية (Firebase)».
2. الصق رابط القاعدة في «رابط قاعدة البيانات السحابية».
3. اترك «مزامنة تلقائية» مفعّلة → **حفظ ومزامنة الآن**.

بعدها: أي عملية تُسجّل على جهاز تُرفع فوراً وتصل بقية الأجهزة خلال أقل من دقيقة (سحب دوري كل 45 ثانية + سحب عند الإقلاع).

### النسخة الكاملة برمز
شاشة **النسخ الاحتياطي** → «المزامنة السحابية (Firebase — رابط ورمز)»:
1. الصق نفس الرابط، واكتب رمزاً (أو اضغط ↻ لتوليده) — **نفس الرمز على كل أجهزتك**.
2. **رفع**: يرفع نسخة كاملة (لن يكتب فوق نسخة سحابية أحدث إلا بتأكيد).
3. **سحب**: يجلب آخر نسخة ويستبدل بيانات الجهاز (بتأكيد، والعملية ذرّية).

### Google Drive (أندرويد)
شاشة النسخ الاحتياطي → «النسخ السحابي عبر Google Drive» → ربط الحساب → رفع/استعادة.
تُحفظ نسخة واحدة باسم `nexora-backup-latest.nexora` في مجلد التطبيق الخاص (لا يرى التطبيق ملفات Drive الأخرى).

## قيود داخل المجموعة (كما هي سياسة التطبيق)
- **الاستعادة** (من ملف أو سحابة أو Google) داخل مجموعة = **جهاز المدير فقط**، وتُزامن تلقائياً لبقية الأجهزة بعد الاستعادة.
- تُرفض أي نسخة احتياطية غير صادرة من نفس المجموعة (بصمة المجموعة).
- العضو لا يرى خيارات Google/السحابة إن كانت صلاحياته لا تسمح.

## استكشاف الأخطاء
| العرض | السبب الغالب | الحل |
|---|---|---|
| «رابط قاعدة البيانات يجب أن يبدأ بـ https://» | رابط http أو ناقص | انسخ الرابط كاملاً من كونسول Firebase |
| `cloud-auth-failed` | القواعد مقيّدة (`auth != null`) وأنت غير مسجّل دخول | سجّل دخول Google داخل التطبيق أو استخدم الخيار أ |
| «النسخة السحابية أحدث من المحلية» | جهاز آخر رفع نسخة أحدث | اسحب أولاً ثم ارفع |
| لا توجد نسخة سحابية لهذا الرمز | الرمز مختلف بين الأجهزة | وحّد الرمز حرفياً على كل الأجهزة |
| Drive: «تسجيل الدخول غير متاح» | ويندوز/لينكس | استخدم أندرويد، أو صدّر ملفاً وارفعه يدوياً |
