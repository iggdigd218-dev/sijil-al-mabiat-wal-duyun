# قواعد Firebase RTDB الموصى بها

## لماذا هذا الملف؟

التطبيق يستعلم سجل العمليات السحابي بـ `orderBy="server_ts"` في:
- السحب التزايدي (`CloudFirebaseTransport.pull`)
- ضغط السجل الدوري (`CloudJoin.compactOperations` — دفعة 57)

بدون فهرس `".indexOn": ["server_ts"]` يرفض الخادم الاستعلام (HTTP 400)
فيتراجع التطبيق إلى **جلب كامل** لعقدة `/operations` — يعمل لكنه
O(كل العمليات) في كل سحب، ويكبر كلفةً مع نمو السجل (البند 7 من تقرير
التدقيق).

## كيفية التطبيق

1. افتح [وحدة تحكم Firebase](https://console.firebase.google.com) → مشروعك.
2. Realtime Database ← تبويب **القواعد (Rules)**.
3. الصق محتوى `database.rules.json` (أو ادمج قسم `".indexOn"` فقط إن
   كانت لديك قواعد مصادقة مخصصة).
4. انشر (Publish).

> **ملاحظة أمنية:** القيم `".read": true / ".write": true` تطابق الوضع
> الحالي للتطبيق (قواعد عامة + توكن Google اختياري). إن فعّلت مصادقة
> إلزامية لاحقاً استبدلها بشروط `auth != null` — التطبيق يرفق
> `?auth=idToken` تلقائياً عند توفر تسجيل دخول Google، ومنذ الدفعة 57
> يفك صلاحية التوكن استباقياً فلا يرسل توكناً منتهياً أبداً.
